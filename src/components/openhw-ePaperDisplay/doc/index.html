2.9" e-Paper Display

Display

A 2.9-inch electronic paper display module communicating via SPI. E-Paper displays are ultra-low power and retain their image even when power is removed.

Pinout

VCCPower supply (typically 3.3V)
GNDGround
DINSPI MOSI (Data In)
CLKSPI SCK (Clock)
CSChip Select (Active Low)
DCData/Command Select
RSTReset (Active Low)
BUSYBusy Status Output

Wiring with Arduino


Arduino 3.3V ────► VCC
Arduino GND  ────► GND
Arduino 11   ────► DIN
Arduino 13   ────► CLK
Arduino 10   ────► CS
Arduino 9    ────► DC
Arduino 8    ────► RST
Arduino 7    ────► BUSY
