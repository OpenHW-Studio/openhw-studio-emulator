MFRC522 RFID Reader

SPI-based RFID reader operating at 13.56 MHz. Reads Mifare Classic 1K cards and key fobs and returns a unique 4 or 7-byte UID. Use with the MFRC522 Arduino library.

PCB Module

The MFRC522 communicates over SPI and reads the unique UID from Mifare Classic RFID cards and key fobs. Each card has a different UID that your sketch can use to grant or deny access.

In OpenHW Studio, right-click the component during simulation to configure card presence and edit the UID. A glowing ripple indicates when a card is actively being detected.

Example Code

⚠️ VCC must be 3.3V only. Connecting to 5V will permanently damage the MFRC522 chip.

Install the MFRC522 library before running.

#include <SPI.h>
#include <MFRC522.h>

#define RST_PIN  9
#define SS_PIN  10

MFRC522 rfid(SS_PIN, RST_PIN);

void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  Serial.println("Hold card near reader...");
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial()) return;
  Serial.print("UID:");
  for (byte i = 0; i < rfid.uid.size; i++) {
    Serial.print(" ");
    Serial.print(rfid.uid.uidByte[i], HEX);
  }
  Serial.println();
  rfid.PICC_HaltA();
}
💡 Use the context menu during simulation to toggle "Card Present" and trigger an RFID scan.
