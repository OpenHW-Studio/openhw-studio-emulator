74HC165 Shift Register

8-bit parallel-in, serial-out (PISO) shift register.

The 74HC165 is used to expand the number of digital inputs available to a microcontroller. It samples 8 parallel inputs and shifts them out serially to the microcontroller using only 3 or 4 pins.

You can cascade multiple 74HC165 chips by connecting the Q7 (Serial Out) of one chip to the DS (Serial In) of the next. This allows you to read 16, 24, 32, or more inputs while using the same microcontroller pins for clock and load.

Pin Reference

PinNameDescription
vccPowerPower supply (3V to 5V).

plParallel Load (SH/LD)Active LOW. When LOW, loads the states of D0-D7 into the shift register. When HIGH, the data can be shifted.
cpSerial Clock (CLK)On the rising edge, data shifts one position (if PL is HIGH and CE is LOW).
ceClock Enable (CLK INH)Active LOW. When HIGH, clock signals on CP are ignored. Often tied to GND if not used.
q7Serial Output (QH)Outputs the final bit of the shift register. Connect to the MCU to read data, or to DS of the next chip for cascading.
q7nInverted Output (QH')Inverted serial output.
dsSerial Input (SER)Data input for cascading. Connect to Q7 of the preceding chip.
