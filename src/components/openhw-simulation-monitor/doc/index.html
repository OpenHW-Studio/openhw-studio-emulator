Simulation Monitor (openhw-simulation-monitor)

The Simulation Monitor is an advanced diagnostic instrument designed to monitor the health, performance, and telemetry bandwidth of the emulation engine in real-time.

Key Metrics Exposed

  • Worker CPU Load: Percentage of time spent executing instructions and serializing state.
  • Canvas FPS Reflection: Estimated rendering frame rate of the React UI based on telemetry payload size.
  • Time Drift & Jitter: Variance between virtual microcontroller time and real wall-clock time.
  • Serialization Bandwidth: Exact byte size of telemetry packets transmitted per frame.
