ILI9341 2.8" TFT LCD with Touch

Display Input

A vibrant 2.8-inch TFT LCD color display driven by the ILI9341 controller over SPI, combined with a capacitive touch screen overlay via an FT6206 or similar I2C controller.

Pinout

VCCPower supply (3.3V or 5V)
GNDGround
CSDisplay Chip Select (Active Low)
RESETDisplay Reset (Active Low)
DCData/Command Select
MOSISPI MOSI (Data In)
SCKSPI SCK (Clock)
LEDBacklight Power
MISOSPI MISO (Data Out)
SCLTouch I2C Clock
SDATouch I2C Data

Wiring with Arduino


Arduino 5V   ────► VCC, LED
Arduino GND  ────► GND
Arduino 10   ────► CS
Arduino 9    ────► DC
Arduino 8    ────► RESET
Arduino 11   ────► MOSI
Arduino 12   ────► MISO
Arduino 13   ────► SCK
Arduino A5   ────► SCL
Arduino A4   ────► SDA
