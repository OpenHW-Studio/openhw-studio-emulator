IR Receiver

38 kHz infrared demodulator. Receives NEC protocol IR signals from a remote control and outputs a clean digital signal. Compatible with the IRremote library.

PCB Breakout Module

The IR receiver demodulates 38 kHz infrared signals and outputs a clean active-LOW digital signal that the Arduino can read. It decodes signals from TV remotes and other IR sources.

In OpenHW Studio, click the component on the canvas during simulation to open a virtual remote control. Press any button to send an IR signal.

38 kHz IR NEC Protocol Active LOW Virtual Remote

Pin Reference

PinTypeDescription
GND (G)InputGround. Connect to Arduino GND.
VCC (V)InputPower supply. Connect to Arduino 5V or 3.3V.
OUT (R)OutputDigital signal output. Connect to any Arduino digital pin. Active LOW — idle state is HIGH, signal bursts pull it LOW.
⚠️ The OUT pin is Active LOW. Idle state = HIGH. Do not connect OUT to an analog pin — it must be a digital pin (D2–D13 recommended).

AttributeDefaultDescription
frequency38Carrier frequency in kHz. Standard is 38 kHz. Options: 36, 38, 40, 56.

▶ Try it in the Simulator

IR Receiver wired to pin 11. Click the component during simulation to open the virtual remote. Press any button — the HEX code prints to the Serial Monitor.

Example Code

Install the IRremote library via the Libraries tab before running this sketch.

#include <IRremote.h>

const int IR_PIN = 11;

IRrecv irrecv(IR_PIN);
decode_results results;

void setup() {
  Serial.begin(9600);
  irrecv.enableIRIn();
  Serial.println("IR Receiver Ready — press a button on the remote");
}

void loop() {
  if (irrecv.decode(&results)) {
    Serial.print("Received code: 0x");
    Serial.println(results.value, HEX);

    // Identify button from code
    switch (results.value) {
      case 0xE0E040BF: Serial.println("POWER");  break;
      case 0xE0E0E01F: Serial.println("VOL+");   break;
      case 0xE0E0D02F: Serial.println("VOL-");   break;
      case 0xE0E016E9: Serial.println("OK");     break;
      default:         Serial.println("Unknown"); break;
    }

    irrecv.resume();
  }
}
