DS18B20 Temperature Sensor

Digital 1-Wire temperature sensor with ±0.5°C accuracy over the range of −10°C to +85°C.

PCB Breakout Module

The DS18B20 is a digital thermometer that communicates over a single data wire using the 1-Wire protocol. Multiple sensors can share the same data line.

In OpenHW Studio, drag the component onto the canvas and use the context menu during simulation to adjust the temperature in real time.

Pin Reference

PinTypeDescription
VCC Input Power supply. Connect to Arduino 5V or 3.3V.
DQ Bidirectional 1-Wire data line. Connect to any Arduino digital pin. Requires a 4.7kΩ pull-up resistor to VCC.
GND Input Ground. Connect to Arduino GND.
⚠️ A 4.7kΩ pull-up resistor between DQ and VCC is required for reliable 1-Wire communication. Without it, readings will fail or be incorrect.

Example Code

Install the OneWire and DallasTemperature libraries via the Libraries tab before running this sketch.

#include <OneWire.h>
#include <DallasTemperature.h>

// DS18B20 DQ pin connected to Arduino pin 2
OneWire oneWire(2);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  sensors.begin();
  Serial.println("DS18B20 Ready");
}

void loop() {
  sensors.requestTemperatures();
  float tempC = sensors.getTempCByIndex(0);
  float tempF = sensors.getTempFByIndex(0);

  Serial.print("Temperature: ");
  Serial.print(tempC);
  Serial.print("°C  /  ");
  Serial.print(tempF);
  Serial.println("°F");

  delay(1000);
}
💡 Adjust the temperature by right-clicking the DS18B20 on the canvas while the simulation is running. The Serial Monitor will immediately reflect the new reading.

How It Works

The DS18B20 uses the 1-Wire protocol — a serial communication bus that requires only a single data wire. Here is the communication sequence:

1. Initialization

The Arduino pulls the DQ line LOW for at least 480µs to reset all devices on the bus, then releases it. The DS18B20 responds with a presence pulse.

2. ROM Command

The Arduino sends 0xCC (Skip ROM) to address all sensors, or 0x55 followed by a 64-bit address to target a specific sensor.

3. Function Command

The Arduino sends 0x44 (Convert T) to trigger a temperature measurement, then reads the scratchpad with 0xBE.

4. Data Format

Temperature is returned as a 16-bit signed integer in units of 1/16°C. For example, 25°C = 0x0190 = 400.

Simulation Notes

In OpenHW Studio, the DS18B20 is simulated at the library abstraction level. The DallasTemperature library calls are intercepted and the simulated temperature value is returned directly — making simulation fast and accurate without bit-level 1-Wire timing.
