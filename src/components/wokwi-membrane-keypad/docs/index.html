4x4 Membrane Keypad

The 4x4 Membrane Keypad provides a simple, flat grid of 16 tactile buttons arranged in 4 rows and 4 columns. It's wildly popular in embedded security systems, calculators, and menu-driven interfaces.

How It Works

Instead of requiring 16 separate inputs (one for each button) plus a ground wire, this keypad uses a clever electronic matrix layout:

  1. The Matrix: The 16 buttons are physically wired into a grid. All buttons in a specific row share one common connection wire, and all buttons in a specific column share another.
  2. 8 Wires Total: This arrangement condenses the required wires down from 17 to just 8 (4 pins for the rows, 4 pins for the columns).
  3. Scanning (Multiplexing): To read a button press, your Arduino repeatedly sets one Row pin LOW temporarily, and checks all Column pins to see if any are pulled LOW. If they are, it knows exactly the intersection point (Row Y, Column X) where a button is currently being short-circuited by a human finger.

Hardware Pinout (Left to Right)

The 8-pin flat flexible cable represents the rows and columns in order from left to right (Pins 1 through 8):

Pin Matrix Section Keys Controlled
R1 (Pin 1)Row 11, 2, 3, A
R2 (Pin 2)Row 24, 5, 6, B
R3 (Pin 3)Row 37, 8, 9, C
R4 (Pin 4)Row 4*, 0, #, D
C1 (Pin 5)Column 11, 4, 7, *
C2 (Pin 6)Column 22, 5, 8, 0
C3 (Pin 7)Column 33, 6, 9, #
C4 (Pin 8)Column 4A, B, C, D

Arduino Code Exampe

You must install the standard Keypad.h library inside your Arduino IDE to effortlessly scan the matrix in the background without manually writing multiplexing logic.

#include <Keypad.h>

const byte ROWS = 4; // Four rows
const byte COLS = 4; // Four columns

// Define the Keymap exactly as it looks physically
char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

// Connect keypad ROW1, ROW2, ROW3 and ROW4 to these Arduino pins.
byte rowPins[ROWS] = {9, 8, 7, 6};

// Connect keypad COL1, COL2, COL3 and COL4 to these Arduino pins.
byte colPins[COLS] = {5, 4, 3, 2}; 

// Create the Keypad library object
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

void setup(){
  Serial.begin(9600);
  Serial.println("System Locked. Enter PIN.");
}
  
void loop(){
  // Read the key (if nothing is pressed, this returns NO_KEY)
  char key = keypad.getKey();
  
  if (key){
    Serial.print("Pressed key: ");
    Serial.println(key);
  }
}
