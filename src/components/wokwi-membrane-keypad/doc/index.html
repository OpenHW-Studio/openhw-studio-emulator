Membrane Keypad

A 4x4 membrane keypad with 16 keys arranged in a telephone-style layout.

Pin Configuration

  • R1-R4: Row pins (output)
  • C1-C4: Column pins (input)

Key Layout

1 2 3 +
4 5 6 -
7 8 9 *
. 0 = /

Usage

The keypad uses a matrix scanning technique and is configured as a calculator-style keypad. To detect key presses:

  1. Set one row pin HIGH (3.3V/5V)
  2. Read all column pins
  3. A column pin reading LOW indicates a pressed key at that intersection
  4. Repeat for each row

Attributes

  • type: Keypad type (4x4 or 4x3)

Example Circuit

Connect row pins to digital output pins and column pins to digital input pins with pull-up resistors.
