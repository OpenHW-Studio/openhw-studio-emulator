NTC Thermistor Module

An analog and digital temperature sensor module using an NTC thermistor and an LM393 comparator.

Comparator Module

This module features an NTC thermistor and an LM393 comparator. It provides both an analog output (A0) representing the raw voltage divider, and a digital output (D0) that triggers LOW when the temperature exceeds a threshold set by the onboard potentiometer.

Adjust the temperature and potentiometer threshold in real-time using the context menu during simulation.

Analog Output Digital Output LM393 Comparator Adjustable Threshold

Pin Reference

Pin Type Description
A0 Analog Out Outputs the raw analog voltage from the internal voltage divider. Connect to Arduino A0.
D0 Digital Out Outputs LOW when temperature crosses the threshold. Connect to any digital pin.
GND Input Ground. Connect to Arduino GND.
VCC Input Power Supply. Connect to Arduino 5V.
⚠️ Unlike a raw NTC component, this module has a built-in 10kΩ series resistor for the voltage divider. You do not need to add external resistors.

Attributes

Attribute Default Description
temperature 25 Temperature in °C. Adjustable live during simulation.
threshold 512 Potentiometer threshold (0-1023). Triggers the D0 pin when crossed.

▶ Try it in the Simulator

The module is wired to Arduino A0 and D2. It reads both the analog temperature and the digital threshold trigger.

Example Code

This code reads the analog pin to calculate the temperature, and the digital pin to check if the temperature has crossed the onboard threshold.

#include <math.h>

const int ANALOG_PIN = A0;
const int DIGITAL_PIN = 2;

// Module constants
const float SERIES_RESISTOR    = 10000.0;  // Onboard 10k resistor
const float NOMINAL_RESISTANCE = 10000.0;  // R0 at 25°C
const float NOMINAL_TEMPERATURE = 25.0;
const float BETA_COEFFICIENT    = 3950.0;

void setup() {
  Serial.begin(9600);
  pinMode(DIGITAL_PIN, INPUT);
}

void loop() {
  int raw = analogRead(ANALOG_PIN);
  int trigger = digitalRead(DIGITAL_PIN);

  // Calculate NTC resistance from voltage divider
  float resistance = SERIES_RESISTOR * raw / (1023.0 - raw);

  // Steinhart-Hart Beta equation
  float tempK = 1.0 / (
    log(resistance / NOMINAL_RESISTANCE) / BETA_COEFFICIENT
    + 1.0 / (NOMINAL_TEMPERATURE + 273.15)
  );
  float tempC = tempK - 273.15;

  Serial.print("Temp: "); Serial.print(tempC); Serial.print("°C");
  
  if (trigger == LOW) {
    Serial.println(" | THRESHOLD CROSSED!");
  } else {
    Serial.println();
  }

  delay(500);
}
