Parallel LCD 20x4

Display

A 20-column by 4-row Liquid Crystal Display module using the standard parallel interface (Hitachi HD44780). It supports both 4-bit and 8-bit modes and works natively with the Arduino LiquidCrystal library.

Default Configuration

Dimensions20 columns, 4 rows
InterfaceParallel (RS, RW, E, D0-D7)

Wiring with Arduino (4-bit mode)


Arduino 5V  ────► VDD (and A)
Arduino GND ────► VSS (and RW, K)
Arduino 12  ────► RS
Arduino 11  ────► E
Arduino 5   ────► D4
Arduino 4   ────► D5
Arduino 3   ────► D6
Arduino 2   ────► D7

Example Code (Arduino)


#include <LiquidCrystal.h>

// Initialize the LCD with the pins: RS, EN, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  // Set up the LCD's number of columns and rows:
  lcd.begin(20, 4);
  
  lcd.setCursor(0, 0); // 0th col, 0th row
  lcd.print("OpenHW Studio!");
  
  lcd.setCursor(0, 1); // 0th col, 1st row
  lcd.print("Parallel LCD 20x4");
}

void loop() {
  lcd.setCursor(0, 3); // 0th col, 3rd row
  lcd.print("Uptime (s): ");
  lcd.print(millis() / 1000);
  delay(1000);
}
