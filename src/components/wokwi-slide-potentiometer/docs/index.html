Slide Potentiometer

A Slide Potentiometer is a type of linear variable resistor. Unlike a rotary potentiometer that you turn, a slide pot moves in a straight line, making it perfect for faders, level controls, and position sensing.

How It Works

Functionally, a slide potentiometer is identical to a rotary one:

  1. Resistive Track: A straight track of resistive material (like carbon) runs along the length of the housing.
  2. Linear Wiper: The knob is attached to a wiper that slides physically along the track as you move it from one end to the other.
  3. Voltage Divider: Applying 5V and GND to the outer terminals creates a voltage gradient. The middle terminal then outputs a voltage representing its linear position.

Hardware Pinout

Pin Function
VCCPower supply. Connect to Arduino 5V.
GNDCommon ground connection.
OUT / SIGAnalog output voltage. Connect to an Analog Pin (e.g., A0).

Using the Emulator

💡 Simulation Testing

In the OpenHW Studio emulator, you can click and drag the slider knob vertically or horizontally to simulate physical movement. Your Arduino code will see the value change smoothly from 0 to 1023.

Arduino Code Exampe

int sliderPin = A0; 

void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(sliderPin);
  Serial.print("Slider Position: ");
  Serial.println(value);
  delay(100);
}
