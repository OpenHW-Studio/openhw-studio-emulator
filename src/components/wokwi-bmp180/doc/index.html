BMP180

I2C barometric pressure and temperature sensor. Measures pressure (300–1100 hPa) and calculates altitude. I2C address: 0x77.

PCB Module

The BMP180 communicates over the I2C bus using address 0x77. It provides barometric pressure, temperature, and calculated altitude. Use with the Adafruit_BMP085 library.

Connect SCL to Arduino A5 and SDA to Arduino A4. Adjust temperature and pressure live during simulation via the context menu.

I2C (0x77) Pressure Sensor Altitude Calculator 300–1100 hPa

Pin Reference

Pin Type Description
VIN Input Power supply. Connect to Arduino 3.3V (preferred) or 5V.
GND Input Ground. Connect to Arduino GND.
SCL Input I2C Clock. Connect to Arduino A5.
SDA Bidirectional I2C Data. Connect to Arduino A4.
⚠️ The BMP180 I2C address is fixed at 0x77. If another I2C device on your bus also uses 0x77, there will be a conflict.

Attributes

Attribute Default Description
temperature 25.0 Temperature in °C (−40 to 85). Adjustable live.
pressure 1013.25 Pressure in hPa. Sea level = 1013.25 hPa. Adjustable live.

Example Code

Install the Adafruit BMP085 library (works for BMP180 too) via the Libraries tab.

#include <Wire.h>
#include <Adafruit_BMP085.h>

Adafruit_BMP085 bmp;

void setup() {
  Serial.begin(9600);
  if (!bmp.begin()) {
    Serial.println("BMP180 not found!");
    while (1) {}
  }
  Serial.println("BMP180 Ready");
}

void loop() {
  float temp     = bmp.readTemperature();
  long  pressure = bmp.readPressure();
  float altitude = bmp.readAltitude();

  Serial.print("Temp: ");     Serial.print(temp);     Serial.println(" °C");
  Serial.print("Pressure: "); Serial.print(pressure); Serial.println(" Pa");
  Serial.print("Altitude: "); Serial.print(altitude); Serial.println(" m");
  Serial.println("---");

  delay(1000);
}
💡 Right-click the BMP180 during simulation to change temperature and pressure. The altitude is calculated automatically using the barometric formula.

How Altitude is Calculated

The BMP180 uses the standard barometric formula to derive altitude from pressure:

altitude = 44330 × (1 − (pressure / 101325)^(1/5.255))

Sea level pressure (101325 Pa) gives altitude = 0m. At the top of Mount Everest (~30000 Pa), altitude ≈ 8848m.
