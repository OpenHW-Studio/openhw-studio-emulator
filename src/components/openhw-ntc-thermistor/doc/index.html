NTC Thermistor Module

Analog and digital temperature sensor using an NTC thermistor and an LM393 comparator. Outputs both a raw analog voltage (A0) and a threshold-triggered digital signal (D0).

NTC Thermistor Module

The NTC Thermistor Module uses a voltage divider (VCC → 10 kΩ fixed resistor → A0 junction → NTC → GND). The analog pin A0 carries a temperature-dependent voltage; the LM393 comparator outputs a digital LOW on D0 when the temperature exceeds the potentiometer-set threshold.

In OpenHW Studio, right-click the component to set the simulated temperature (°C) and comparator threshold (0–1023). Click the potentiometer on the canvas to step the threshold in increments of 128.

💡 The threshold represents an ADC value (0–1023). The comparator trips when the A0 voltage falls below VCC × (threshold / 1023). A higher threshold means the digital output triggers at a lower temperature.

How It Works

The NTC resistance drops as temperature rises (negative temperature coefficient). The voltage divider formula gives:

V_A0 = VCC × R_NTC / (10000 + R_NTC)

R_NTC is calculated from the Steinhart–Hart Beta equation:

R_NTC = R_nominal × exp( β × (1/T − 1/T₀) )

where T and T₀ are in Kelvin, β = 3950 (default), R_nominal = 10 kΩ at 25 °C.

D0 goes LOW when V_A0 < V_threshold, i.e. when the temperature is above the set point.

Example Code — Analog Temperature

Read the NTC voltage from A0 and convert it to a temperature using the Beta equation.

const float BETA          = 3950.0;  // Beta coefficient
const float R_NOMINAL     = 10000.0; // NTC resistance at 25 °C
const float T_NOMINAL     = 25.0;   // Nominal temperature (°C)
const float R_SERIES      = 10000.0; // Fixed series resistor (10 kΩ)
const int   NTC_PIN       = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int raw = analogRead(NTC_PIN);           // 0 – 1023
  float vout = raw * (5.0 / 1023.0);    // Convert to voltage

  // Back-calculate R_NTC from voltage divider
  float rNTC = R_SERIES * vout / (5.0 - vout);

  // Steinhart-Hart Beta equation → temperature in Kelvin
  float tempK = 1.0 / ((1.0 / (T_NOMINAL + 273.15)) +
                        (1.0 / BETA) * log(rNTC / R_NOMINAL));
  float tempC = tempK - 273.15;

  Serial.print("Temperature: ");
  Serial.print(tempC, 1);
  Serial.println(" °C");
  delay(1000);
}

Example Code — Digital Threshold Alert

Use D0 to trigger an action when the temperature exceeds the potentiometer-set threshold.

const int D0_PIN = 2;   // Digital output from NTC module

void setup() {
  pinMode(D0_PIN, INPUT);
  Serial.begin(9600);
}

void loop() {
  int state = digitalRead(D0_PIN);
  if (state == LOW) {
    Serial.println("⚠️  Over-temperature alert!");
  } else {
    Serial.println("Temperature OK");
  }
  delay(500);
}
💡 D0 is active LOW — it pulls to 0 V when the temperature is above the threshold. Use digitalRead() == LOW to detect the trigger condition.
⚠️ Adjust the blue potentiometer on the module to set the trip temperature. Turning it clockwise raises the threshold (triggers at higher temperatures). In the simulator, right-click and change the threshold attribute (0–1023).
