BMP180 Pressure Sensor

I2C barometric pressure and temperature sensor by Bosch. Reports pressure (Pa), temperature (°C), and calculated altitude (m). Compatible with the Adafruit_BMP085 library.

PCB Breakout Module (3× scale)

The BMP180 communicates over I2C (address 0x77) and reports barometric pressure and ambient temperature. Altitude is calculated from pressure using the standard barometric formula.

In OpenHW Studio, right-click the component on the canvas to set the simulated pressure (hPa) and temperature (°C) before or during a simulation run.

Example Code

Install the Adafruit BMP085/BMP180 library via the Libraries tab, then upload this sketch.

#include <Wire.h>
#include <Adafruit_BMP085.h>

Adafruit_BMP085 bmp;

void setup() {
  Serial.begin(9600);
  if (!bmp.begin()) {
    Serial.println("BMP180 not found — check wiring!");
    while (1);
  }
  Serial.println("BMP180 ready.");
}

void loop() {
  float temp = bmp.readTemperature();      // °C
  long  pres = bmp.readPressure();          // Pa
  float alt  = bmp.readAltitude();          // metres (sea-level ref)

  Serial.print("Temp: ");
  Serial.print(temp);
  Serial.println(" °C");

  Serial.print("Pressure: ");
  Serial.print(pres);
  Serial.println(" Pa");

  Serial.print("Altitude: ");
  Serial.print(alt);
  Serial.println(" m");

  Serial.println("---");
  delay(2000);
}
💡 Right-click the BMP180 component on the canvas during simulation to change the simulated pressure and temperature values in real time.
⚠️ The BMP180's I2C address is hardwired to 0x77. If another device on the same bus shares that address (e.g. a BMP085), only one can be used at a time.

Altitude Calculation

The altitude reported by readAltitude() assumes sea-level reference pressure of 101 325 Pa. For a more accurate local reading, pass your current sea-level pressure to readAltitude(seaLevelPa):

// Use local sea-level pressure (e.g. from a weather station) for accuracy
float seaLevelPa = 101800;   // example: 1018 hPa
float alt = bmp.readAltitude(seaLevelPa);

The formula used internally is:

altitude = 44330 × (1 − (pressure / seaLevelPressure)1/5.255)
