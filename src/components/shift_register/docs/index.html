74HC595 Shift Register

The 74HC595 is an 8-bit serial-in, parallel-out shift register. It is a fundamental building block in digital electronics that allows you to "expand" the number of output pins on your Arduino—controlling 8 outputs using only 3 digital pins.

How It Works

The chip works like a small memory shelf with 8 slots:

  1. Serial Input (DS): You "push" bits (1s or 0s) into the chip one by one.
  2. Shift Clock (SHCP): Every time this pin pulses, the internal "shelf" moves over, making room for the next bit.
  3. Storage Clock (STCP): Also called the Latch. When you pulse this pin, the 8 bits you just pushed in are pushed out to the physical pins (Q0-Q7) all at once.
  4. Daisy Chaining: By connecting the Q7' pin of one chip to the DS pin of another, you can chain multiple registers to control 16, 24, or even 100+ outputs from the same 3 Arduino pins!

Arduino Code Exampe (shiftOut)

#define SER   11
#define SRCLK 12
#define RCLK  8

void setup() {
  pinMode(SER, OUTPUT);
  pinMode(SRCLK, OUTPUT);
  pinMode(RCLK, OUTPUT);
}

void writeRegister(byte data) {
  digitalWrite(RCLK, LOW);
  // Shift out the 8 bits
  shiftOut(SER, SRCLK, MSBFIRST, data);
  // Latch the data to the outputs
  digitalWrite(RCLK, HIGH);
}

void loop() {
  for (int i = 0; i < 8; i++) {
    writeRegister(1 << i);   // Light each output in sequence
    delay(200);
  }
}
